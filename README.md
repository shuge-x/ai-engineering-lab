# AI Engineering Lab

面向中文开发者的 AI 编程工程实践实验室。以 Matt Pocock Skills 为主工作流，以 CodeGraph 补充代码结构知识，通过任务故事、机制演示和知识关系图帮助开发者掌握实际工程方法。

## 在线站点

https://shuge-x.github.io/ai-engineering-lab/

## 学习入口

首页采用无左侧栏的全宽任务入口，并将六种工作流组织为三个学习领域：

- **01 需求与架构**：需求探索与设计、大型架构与跨会话。
- **02 开发与交付**：快速修改、常规功能开发。
- **03 质量与演进**：复杂 Bug 诊断、架构优化与重构。

顶部领域导航与首页内容联动。课程详情页保留左侧目录，方便在深入学习时切换工作流。

## 三种学习模式

- **任务入口**：从真实开发问题、适用边界和推荐学习路径进入。
- **机制演示**：查看工作流机制与关键决策，可逐步推进。
- **知识图谱**：查看用户意图、Skills、工程工件、测试与知识沉淀之间的概念关系。

课程详情另提供阶段导航、机制 / Prompt / 来源讲解，以及底部执行轨迹。

## 当前阶段：交互工作台骨架

- 六种工作流及各自开发故事、适用条件、主流程和常见错误。
- 阶段角色、产物、交接规则和可复制操作指令。
- 项目知识与 CodeGraph 专题。
- 测试、验证与真实验收专题。
- Matt Skills 索引。
- 中文内容、深色主题、移动端适配和本地学习进度。

当前优先保证课程体系骨架与关键机制清楚，后续逐步补充更深入的操作示例、真实工件、图解和来源注释。

## 内容准确性原则

- Skill 名称、调用权限和工作流以 Matt 上游仓库当前版本为准。
- CodeGraph 是代码结构索引，不是业务知识库、通用 SQL 血缘工具或运行时正确性验证器。
- 自动化测试通过不等于需求满足，更不等于人工验收完成。
- 教学案例是实践建议，不应描述为上游工具保证自动执行的行为。

## 本地预览与部署

纯静态站点，无需后端或安装依赖。可直接打开 `index.html`，也可使用任意静态 HTTP 服务。GitHub Actions 会校验脚本和课程数据后部署 GitHub Pages。
